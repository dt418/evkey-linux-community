01

Input modes

  • PreeditShows the active composition before commit; no privileged helper is needed.
  • Fake BackspaceReplaces an engine-owned suffix through application-directed Backspace events and committed text; no privileged helper is used.
  • Smooth / UinputAn optional mode using the helper's virtual keyboard for editing keys. Composed text still travels through Fcitx, not through the helper.

Requested mode can differ from effective mode in each input context. Fallback depends on compatibility and helper availability; interrupted replacement is not blindly replayed.

02

Helper boundary

Installing fcitx5-evkey-uinput and enabling its service are separate decisions. The optional helper receives bounded editing-key requests over AF_UNIX, checks peer UID plus active, local, unlocked session state, then may emit through /dev/uinput.

The helper does not receive composed text, does not read raw keyboard devices, and cannot promise an application will apply an edit. Review local distro, systemd, and udev policy before enabling it.

03

Build from source

There is no generic download button. Full instructions, dependencies, and packaging recipes live in the repository at the linked snapshot.

  1. Install Linux dependencies from the build instructions.
  2. Configure, build, and test in a source checkout.
  3. Install the Runtime component separately; install Uinput only after evaluating the optional helper.
cmake -S . -B build -DCMAKE_INSTALL_PREFIX=/usr -DBUILD_TESTING=ON
cmake --build build --parallel
sudo cmake --install build --component Runtime
