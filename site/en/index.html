Vietnamese input on Linux

Type Vietnamese through Fcitx5.

EVKey Linux Community is an independent Vietnamese input method for Linux, based on Fcitx5 Lotus and Bamboo. It is inspired by EVKey; it is not the official EVKey release, and is neither affiliated with nor endorsed or distributed by EVKey’s author.

Features

  • Input methodsTelex, VNI, Telex + VNI, Telex + VNI + VIQR, VIQR, Microsoft layout, VNI French keyboard and Custom.
  • Output charsetsUnicode and legacy Vietnamese encodings including TCVN3, VNI Windows, VIQR, VPS, VISCII and Windows 1258.
  • Fcitx5 controlsChoose Input Method and Charset, or open Settings from the status menu.

Choices reflect the engine’s supported options; some input methods or charsets serve legacy compatibility needs.

02

How to use

  1. Install EVKey Linux Community with Fcitx5, then add EVKey Linux Community to Fcitx5’s input method list.
  2. Use the Fcitx5 status menu → Input Method to choose Telex, VNI or another method.
  3. Choose an output encoding from Charset. Open Settings to configure text display and replacement behavior.

Telex example: Tooi ddang gox tieengs Vieetj. → Tôi đang gõ tiếng Việt. VNI: tie61ng Vie65t → tiếng Việt.

Choose an input mode: Preedit composes text separately before commit. Fake Backspace replaces a suffix using the application’s Backspace key and needs no helper. Optional Smooth/Uinput uses a separate helper for editing keys. The helper does not receive composed text or read raw keyboard input. Compatibility depends on the application; start with Preedit if unsure.

03

Downloads and installation

There are no packaged Linux binaries in Releases yet. Download the source ZIP to build locally; the README covers dependencies and installing the Runtime component.

Smooth/Uinput requires the optional fcitx5-evkey-uinput helper package. Installing the helper and enabling its service are separate choices. Preedit and Fake Backspace do not require it.
